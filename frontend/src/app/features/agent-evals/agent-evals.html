Agent Evaluations

Every agent call is recorded here with how long it took, what it cost in tokens, and how good the answer was. Open a call to see what the agent was given, what it said, and to rate it yourself.

help_outline How each metric is scored
Groundedness
For a written answer: the share of its sentences supported by the context the agent was given (a sentence counts as supported when its closest context sentence is at least 55% similar). For Document Intake: the share of extracted values found in the passage they were read from. Only model-written answers are scored; rule-based and retrieval-only answers are assembled from their context, so scoring them would be meaningless.
Context relevance
How closely the passages the agent retrieved matched what it was looking for (average cosine similarity).
Answer relevance
How closely the answer matches the question or stage focus it was asked (cosine similarity).
Accuracy
Never guessed by a model — it comes from what people did with the output: the share of extracted values a reviewer accepted unchanged (Document Intake), the share of proposed changes an approver approved (stage and Borrowing Base agents), or a thumbs up/down (ABL Wiki, or any call you rate yourself).
A note on the proxies
Groundedness and relevance use the same embedding model as retrieval, so they are fast, free and repeatable, but they are proxies. Open a call to see which sentences were flagged and judge for yourself.
